## Parameters

- Seed: 42
- Target ratios (approved): train 70%, val 20%, test 10%

- Unit of splitting: photograph group, formed within each class; linked when pixel similarity >= 0.75 (brightness-, flip- and rotation-invariant) or ResNet50-feature cosine similarity >= 0.85
- Minimum groups per class in each split: 2
- Images kept: 865; excluded: 73, of which 73 were in the Stage 3 list of 73 (see `reports/excluded_images.csv`)

## Notes

- The split used only class labels, group membership and group sizes. No image content beyond the near-duplicate grouping and no model result was used.
- The test set must not be used for model selection or tuning (Stages 5 to 7).
- All data come from one source (the Roboflow export). No external test set exists; generalisation to other photographers, devices and regions is untested.
